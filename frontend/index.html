What is CyberReport?

CyberReport is a lightweight, offline-first vulnerability assessment report generator built for security professionals. Upload a structured findings file and instantly receive a clean, professional PDF — no cloud, no AI API, no third-party processing.

🔒 100% Offline Your data never leaves your machine

// HELP

How to Format Your File

Your .txt file should use the following tags at the start of each line. Each tag tells the report engine how to categorize that finding.

[VULN]
Vulnerability Finding CVE-2023-1234 — SQL Injection found in /login endpoint
[SCAN]
Scan Tool Output Nmap: Port 22 open — OpenSSH 7.2 (outdated version)
[NOTE]
Pentest Notes Weak password policy found — admin:admin123 still valid
[PROOF]
Evidence / Screenshots Screenshot shows exposed API key in JS source file
[TARGET]
Target Information 192.168.1.1 — Internal web server
[DATE]
Assessment Date 2024-11-15
💡 Multi-line entries are supported — just continue writing on the next line without a new tag. A blank line ends the current block.
