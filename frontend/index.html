// ABOUT

What is CyberReport?

CyberReport is a lightweight, offline-first vulnerability assessment report generator. Upload structured findings files and get a professional PDF — complete with Table of Contents, severity chart, open ports table, and remediation guidance. No cloud, no AI API, no third-party processing.

🔒100% OfflineYour data never leaves your machine
⚡Real ProgressLive backend polling, not fake timers
📁Multi-fileMerge Nmap JSON + manual notes together
📋Pro FormatToC, risk chart, exec summary, remediation
// HELP

How to Format Your File

Your .txt file uses tags below. Your .json file (Nmap/tool output) is auto-detected and parsed directly. You can upload both together.

[VULN]
Vulnerability FindingCVE-2023-1234 — SQL Injection in /login endpoint
[SCAN]
Scan Tool OutputNmap: Port 22 open — OpenSSH 7.2 (outdated)
[NOTE]
Pentest NotesWeak password — admin:admin123 still valid
[PROOF]
EvidenceScreenshot shows exposed API key in JS source
[TARGET]
Target Info192.168.1.1 — Internal web server
[DATE]
Assessment Date2024-11-15
💡Upload multiple files at once — e.g. one JSON from Nmap and one TXT with manual notes. They'll be merged into a single professional report.
